# Glossary

Status is for the term as a lore word. Project: TCG = Magic vs Martial, RPG = beautiful-tree, SB = still-blade.

| Term | Meaning | Status | Project |
|---|---|---|---|
| Magic | Energy drawn from the environment, generated by life; innate gift only, which must still be trained | CANON idea, PLACEHOLDER word | TCG |
| Martial | Energy cultivated from within through training; anyone can learn it | CANON idea, PLACEHOLDER word | TCG |
| Hybrid | A rare person or spec holding both energies, which oppose each other in the body | CANON | TCG |
| Discipline | Magic or Martial (the energy a spec uses) | DRAFT | TCG |
| Spec | Combat specialization, joined through a quest after training | DRAFT (working word) | TCG |
| Class | In the RPG, a combat class earned in game before a spec; the base of a character's combat abilities | DRAFT (working word) | RPG |
| Attacker / Defender / Ranged / Magic (paths) | The four broad paths fighters are trained into from youth in still-blade's region | PLACEHOLDER | SB |
| Line Strike / Wide Sweep / Piercing Shot | Weapon skill shots (blade, polearm, bow) | PLACEHOLDER | SB |
| Second Wind / Guard / Fan Shot | Path skills (Attacker, Defender, Ranged); Second Wind also a TCG Martial healing name | PLACEHOLDER | SB |
| Skyiron / Starheart / Shardstone | Sky-fallen materials that raise gear's level, quality and plus | PLACEHOLDER | SB |
| Strike / Guard / Vigor / Swift Gem | Gems set into gear sockets; each raises one stat (grades I-III) | PLACEHOLDER | SB |
| Sub-spec | A possible secondary specialization at a higher rank | DRAFT | TCG |
| Tempest / Binders / Bulwark / Reavers | The four specs (destruction, control, defense, aggression) | PLACEHOLDER | TCG |
| Champion | A named character of the world who commands one side of a match | CANON | TCG |
| Command | The commander bringing more forces to the front as a battle develops | PLACEHOLDER | TCG |
| Charge | A unit of Magic or Martial energy available to a Champion each turn | PLACEHOLDER | TCG |
| Caster | A Magic unit; channels Spells | DRAFT | TCG |
| Spell | A Magic card or effect | DRAFT | TCG |
| Technique | A Martial card or effect; the only kind usable mid-combat | DRAFT | TCG |
| Order | A one-shot effect any Champion can give, paid with Command only | DRAFT | TCG |
| Arrival | Effect when a unit enters the battle | PLACEHOLDER | TCG |
| Last Echo | Effect when a unit dies | PLACEHOLDER | TCG |
| Token | A summoned unit that isn't a card; lore word open | PLACEHOLDER | TCG |
| Lane | One strip of the battlefield where two units face each other | DRAFT | TCG |
| Rift / Rift Walk | Magic that attacks through any lane; "rift" undefined | PLACEHOLDER | TCG |
| Gathering | Mages drawing on the life a dying unit releases | DRAFT | TCG |
| Stalwart | A defender making every blow at the commander cost the attacker | DRAFT | TCG |
| Overchanneling | Taking extra Magic now at the cost of the next turn | PLACEHOLDER | TCG |
| Bloodrush | Martial energy gained from kills in combat | PLACEHOLDER | TCG |
| Witch / Witch Hunter | "Witch" names a Magic user; the Witch Hunter is a Martial anti-magic fighter | DRAFT | TCG |
| Vanguard / Rear | The two rows of the old TCG board; retired | PLACEHOLDER (retired) | TCG |
| Mana / Energy / Rage / Focus | Power resources in the RPG prototype | DRAFT | RPG |
| Fireball / Frost Bolt | Fire and frost projectile spells | DRAFT | RPG |
| Mend | Self-heal spell | DRAFT | RPG |
| Strike | Melee ability | DRAFT | RPG |
| Evade | Enemy pulled too far from home resets, fully healed | Mechanic only | RPG |
| Quartermaster | RPG quest-giver NPC; also a dwarf TCG card | DRAFT | Both |
| Training Dummy | Practice target / tutorial enemy | PLACEHOLDER | RPG |
| Alpha Island | The RPG test zone | PLACEHOLDER | RPG |
